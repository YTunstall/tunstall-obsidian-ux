Breadcrumbs help users understand where they are within a website or application. They display the path from the Home page to the current page, making the site's navigation hierarchy clear and easy to follow. By providing immediate context and orientation, breadcrumbs also reduce cognitive load, allowing users to quickly understand their location and navigate efficiently.

Location-based breadcrumbs shows the static site structure, an example of this can look like this:

>Home > Clothing > Shirts

A user's current location can be highlighted in several ways:

- Icons or visual indicators
- Color changes
- Bold text
- Indented buttons or menu items
- Different button colors to indicate the active state
